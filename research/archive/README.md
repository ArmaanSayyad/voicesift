# Development archive

Historical plans, feasibility probes and complete evaluation reports retained for reproducibility. These are not the end-user documentation. Use the [documentation index](../../docs/README.md) for current guides and selected experiments. Recorded evidence remains under `evidence/` at the repository root.

Earlier Laya, conversation-repair and interruption-first plans describe stages of development, not VoiceSift’s current project scope. The present goal is LALM-based voice dataset curation from freeform text objectives; see [current capabilities](../../docs/README.md#project-scope-and-current-capabilities). Historical measurements and protocols remain unchanged.
